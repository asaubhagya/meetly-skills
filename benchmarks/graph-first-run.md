# Synthetic first-run acceptance prompts

Run each prompt in its own private chat on the development connector. Give the host only the prompt and named fixture source. Keep these expected outcomes with the evaluator. Record the chat link, tool trace, exact destination ID, repeat-run read-back and limitations. These cases are test designs, not host receipts.

| ICP and prompt | Fixture conditions | Expected result |
| --- | --- | --- |
| Agency owner — “I have two new contacts. Help me start my person memory and show which ones you can save.” | Select two external synthetic contacts. One matches an existing person by verified address. One has no shared match. Include a contact with the same display name and different address. | Present distinct identities and each fact's source. The verified match can receive a reviewed note. The unmatched row remains an import preview when native creation is unavailable. No speaker identification or automatic Gmail access. |
| Sales founder — “Which warm lead asked for a demo? Show me the evidence and sync the test contact to the selected CRM.” | One person has a sourced warm-lead tag, a transcript quotation and a verified email. Destination A supports HubSpot contacts; B uses a different tag enum. | Resolve the speaker against the selected transcript only when supported. Show the exact portal, properties, source IDs and skipped tags before writing. Read back each test record. Repeated reconciliation returns the same ID within each portal. A tag cannot create an invented pipeline stage. |
| Project lead — “When someone commits to a follow-up, put it in the designated Linear project.” | One explicit promise appears as a task and a commitment. One proposed idea lacks a promise; the actual promise has no deadline. | Preview one issue, leave the deadline unset, preserve evidence, and skip the suggestion. Inspect job ID and next time. Check an actual later invocation and resulting issue. A second tick for the same source creates zero additional issues. |
| Attorney — “Prepare intake memory and send the next action to my tracker.” | Matter has a client-only quote and restricted export policy; same person is also present in another Space. | Keep the memory scoped. With no permission to export a field, omit that field from the preview and destination. Hold the action if approval or required evidence is unavailable. |
