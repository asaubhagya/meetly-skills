# Connect your Meetly graph

Read the installed Meetly tool catalog and call the usage guide for connection state. Discover the graph capabilities for this grant. Record the connected account, permitted operations, available entity kinds, snapshot freshness and Space visibility when the server supplies them. A successful meeting read proves meeting access only. If graph discovery is absent, explain which connection needs updating and offer the available meeting workflow. If native publication is pending, follow the returned device instructions.

Use the user's stated goal and Space, or ask which outcome and Space they want. For an established connection, show one feasible next action based on an accessible record and the connected destination. For a new connection, guide the person through selecting a Space in Meetly, granting the named client access, publishing the authorized data, and repeating discovery. Request write access only for the chosen write operation.

For relationship work, inspect one account, its linked person and conversation references. For project work, inspect one project and a linked commitment. For events, begin with the event and follow only permitted links. For legal matters, start with the authorized matter metadata and separately verify permission before exporting any field. Shared person identities can span multiple Spaces. Restrict evidence to the chosen Space even when another relationship is visible.

Show a first-run preview with source IDs, fields, destination and proposed changes. Use the CRM or task workflow for the selected destination. Explain any missing grant, entity or association in terms of discovery results. Finish with the saved destination ID and verified write-back state, or the exact step awaiting approval.
