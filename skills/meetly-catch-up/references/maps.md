# Evidence-backed maps

Use a small table or diagram when relationships, alternatives or dependencies are
clearer visually than in prose. Keep nodes meaningful and edges supported by cited
transcript passages. Mark inferred links and unresolved relationships explicitly.

Prefer the host's native diagram/document tools. Build an interactive artifact only
when requested or genuinely useful for exploration and supported by the host.
Retain a readable chat explanation and source references. Do not fabricate clickable
nodes, download URLs or files. A diagram is an optional view of the evidence, never
a substitute for reading it.
