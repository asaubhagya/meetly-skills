# Sales analysis reference

[Gong's call review guidance](https://help.gong.io/docs/review-what-happened-in-a-call)
illustrates combining a transcript with related account and deal context. Use the
actual connected records and the company's qualification criteria; do not invent
a sales process because a popular framework exists.

Ask what the buyer actually needs, how the current approach fails, who can approve,
what evidence is requested and which next action was accepted. A security condition
is an evaluation requirement, not simply resistance to overcome. If a seller's
claim conflicts with company evidence, correct it in the proposed follow-up.

Attribute commitments and preserve ambiguous dates, currency and scope. A dated CRM
entry is neither automatically authoritative nor automatically fraudulent. Explain
the discrepancy and proposed correction; do not perform a write as part of analysis.
